title: This website
summary: My personal corner of the internet, built step by step with Claude.
stage: in-progress
stack:
  - name: Astro
    role: Turns simple text files into fast web pages, so adding a book or a thought means writing one file.
  - name: GitHub
    role: Keeps the code and its history. Every change is proposed and reviewed as a pull request.
  - name: GitHub Actions
    role: Checks automatically that the site still builds before anything is merged.
  - name: Netlify
    role: Hosts the site, publishes every merged change, and gives each pull request its own preview link.
  - name: Claude Code
    role: My building partner. I describe what I want, and we design and build it together.
---

I wanted one place that tells my story the way I would tell it: my career, how I see the world, and the things I build. Instead of a template, we built it properly from scratch, with each change going through a pull request I review before it goes live.

The code is public on [GitHub](https://github.com/ikiochoa/laura-ochoa), if you are curious how it works.

The look is called Mercado: the colors of Mexican markets on clean, straight lines, for a bit of sun in foggy Zurich.
